# Groups of issues

List of label names for maintenance task groups:

|    Label    | Description                       |
|:-----------:|-----------------------------------|
| **`g:rel`** | Releases                          |
| **`g:fea`** | New features                      |
| **`g:imp`** | Improvements and refactoring      |
| **`g:fix`** | Bug fixes                         |
| **`g:dep`** | Dependency upgrades               |
| **`g:doc`** | Documentation and website updates |
| **`g:res`** | Research                          |
| **`g:sec`** | Security                          |
